자주 묻는 질문

SENTIO에 대해 궁금한 점을 정리했습니다.

기존 CCTV를 교체해야 하나요?

+

아닙니다. SENTIO는 기존에 설치된 CCTV를 그대로 활용합니다. RTSP 프로토콜을 지원하는 IP 카메라 또는 USB 웹캠이면 바로 연결 가능합니다. 추가 하드웨어 구매가 필요 없어 도입 비용이 최소화됩니다.

GPU(그래픽카드)가 필요한가요?

+

GPU 필수가 아닙니다. ONNX 자동 최적화가 적용되어 GPU 유무에 따라 최적 형식을 자동 선택합니다. GPU가 있으면 CUDA 가속(약 26ms/프레임), GPU가 없으면 ONNX Runtime으로 CPU에서도 약 42ms/프레임으로 실시간 처리가 가능합니다. 같은 모델 가중치를 사용하므로 정확도 차이는 없습니다. GRU 추론은 0.3ms/인원으로 매우 가볍습니다.

환자 영상이 외부로 유출될 위험은 없나요?

+

SENTIO는 온프레미스(병원 내부 서버) 방식으로 운영됩니다. 영상 데이터가 외부 클라우드로 전송되지 않으며, AI 분석 후 원본 영상은 즉시 폐기됩니다. 스켈레톤 모드를 사용하면 영상 자체가 관절점 좌표로만 처리되어 환자 식별이 원천적으로 불가능합니다.

감지 정확도 95.2%는 어떻게 검증되었나요?

+

AIHub 공개 데이터셋의 낙상 영상 400개(후방·전방·측면 각 100개 + 정상 100개)와 자체 촬영 데모 영상 24개, 총 424개 영상으로 벤치마크를 수행했습니다. V1부터 V4까지 4개 버전을 동일 조건에서 비교하였으며, 최종 V4에서 Recall 95.2%, Precision 94.6%, F1 94.9를 달성했습니다.

오탐(False Positive)이 많으면 알람 피로가 생기지 않나요?

+

SENTIO는 13가지 규칙 기반 필터 + GRU 딥러닝 이중 검증 + EMA 스무딩 + Standing FP 필터 등 다중 오탐 방지 메커니즘을 적용합니다. 424개 영상 벤치마크에서 정상 동작 100건 중 오탐은 17건(83% 정확 기각)으로, 실무에서 알람 피로를 최소화합니다. 임계값은 설정에서 병원 환경에 맞게 조정 가능합니다.

도입까지 얼마나 걸리나요?

+

Docker 기반 원클릭 배포를 지원하여, 기존 네트워크 인프라가 갖춰진 환경에서는 반나절 이내 설치 완료가 가능합니다. 카메라 RTSP 주소만 등록하면 즉시 모니터링이 시작됩니다. 별도의 서버 구축이나 복잡한 설정 없이 빠르게 시작할 수 있습니다.
