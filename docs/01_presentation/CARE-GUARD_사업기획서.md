> 작성일: 2026-02-02

## 1. 기획 배경

### 1.1 고령화 사회와 요양 시설 현실

- 한국 65세 이상 인구 비율 **19.2%** (2025년 기준, 초고령사회 진입 임박)
- 요양병원 및 요양원 수: 전국 **4,000개 이상**
- 요양병원 내 낙상 사고는 입원 환자 안전사고의 **1위**

### 1.2 낙상의 위험성

| 항목 | 수치 |
|------|------|
| 65세 이상 연간 낙상률 | **30%** |
| 낙상 후 골절 발생률 | **20~30%** |
| 대퇴골 골절 후 1년 내 사망률 | **20~30%** |
| 낙상 후 평균 입원 기간 증가 | **2~3배** |
| 요양병원 낙상 사고 건수 (연간) | **약 25,000건** |

### 1.3 의료기관평가인증원 낙상 주의경보

- **의료기관평가인증원**은 낙상을 **환자안전 주의경보**로 지정하고, 의료기관의 적극적 예방 활동을 권고
- 환자안전보고학습시스템(KOPS) 기준 낙상 사고 연간 **6,199건** 보고 (실제는 10배 이상 추정)
- **환자안전법 제12조**: 의료기관은 환자안전사고 예방 체계를 구축할 의무
- 의료기관 인증 평가 시 **낙상 예방 프로그램 운영 여부**가 핵심 평가 항목
- 2025년 개정 환자안전기준에서 **ICT 기반 모니터링 시스템 도입**이 가산점 요소로 추가

> SENTIO는 의료기관평가인증원의 낙상 주의경보에 대한 **즉시 대응 솔루션**으로 포지셔닝합니다.

### 1.4 현재 모니터링의 한계

- **인력 부족**: 간호사 1인당 환자 30~40명 (야간 더 심각)
- **CCTV 한계**: 단순 녹화, 실시간 감시에 간호사 상주 필요
- **반응 지연**: 낙상 후 발견까지 평균 **30분~2시간**
- **야간 취약**: 주간 대비 야간 낙상 사고 **2배** 증가

## 2. 기획 목적

### 2.1 핵심 목표

**AI 기반 실시간 낙상 감지 시스템을 통해 요양병원의 환자 안전을 혁신적으로 개선**

### 2.2 구체적 목표

1. **즉시 감지**: 전조 감지 시 **1.5초 이내** 주의 알림, 실제 낙상 시 **즉시** 위험 알림 (골든타임 10초 확보)
2. **24시간 무인 모니터링**: AI가 카메라 영상을 쉬지 않고 분석
3. **다채널 알림**: 대시보드 + 푸시 알림 + (향후) SMS로 확실한 전달
4. **프라이버시 보호**: 스켈레톤/블러 모드로 개인정보 보호
5. **낮은 도입 장벽**: 웹 기반 + PWA로 별도 앱 설치 불필요

## 3. 주요 기능

### 3.1 실시간 카메라 영상 분석

- **YOLO11 + MediaPipe 하이브리드**: YOLO11s-pose로 다중 인원 감지, MediaPipe로 정밀 자세 추정
- **33개 관절점** 인체 자세 인식 (MediaPipe PoseLandmarker)
- **다중 인원 감지**: 동시에 N명의 환자 모니터링 가능
- CPU만으로 **~55 FPS** 실시간 처리 (GPU 불필요)
- 프라이버시 모드: skeleton (뼈대만), blur (흐림), full (원본)

### 3.2 4조건 복합 낙상 감지

| 조건 | 감지 내용 |
|------|-----------|
| 머리-엉덩이 역전 | 머리가 엉덩이보다 낮아지면 낙상 의심 |
| 급격한 하강 | 수직 위치가 급격히 떨어지는 속도 감지 |
| 수평 각도 | 신체 축이 수평에 가까워지면 감지 |
| 복합 점수 | 위 조건들의 가중 합산 점수 |

### 3.3 3단계 차등 알림 시스템

```
[전조/저확신]
  정상 → 모니터링 → [1.5초] → 주의(경고음) → [5초] → 위험(전체화면)
                     ↓                                    ↓
                 정상 복귀                              확인 버튼

[실제 낙상 (front/back/side)]
  정상 → 즉시 위험(전체화면 + TTS + Push) ← 골든타임 10초 확보
```

- **주의 단계**: 경고 배지 + 알림음 + 진동
- **위험 단계**: 전체화면 모달 + 강한 알림음 + TTS 음성 + 강한 진동 + 푸시 알림
- **실제 낙상 즉시 위험**: AI가 front/back/side_fall로 분류하면 대기 시간 없이 즉시 위험 알림

### 3.4 실시간 웹 대시보드

- WebSocket 기반 실시간 데이터 업데이트 (지연 < 100ms)
- MJPEG 비디오 스트림 + 스켈레톤 오버레이
- 실시간 메트릭: FPS, 신뢰도, 감지 상태
- 이벤트 로그: 모든 낙상 이벤트 기록 및 조회 (ARIA live region)

### 3.5 보안 및 인증

- **HttpOnly 쿠키 기반 인증 (Access 8시간 + Refresh 7일, XSS 방어)**
- 역할 기반 접근 제어 (admin/staff)
- 로그인 레이트 리밋 (IP별 5회/60초)
- 전 엔드포인트 인증 필수
- **DB 마이그레이션**: Alembic (async, SQLite batch mode)
- **CI/CD**: GitHub Actions 자동 테스트 (pytest + tsc + vite build)

### 3.6 PWA 및 푸시 알림

- 홈 화면 설치 (앱처럼 사용)
- Service Worker 기반 오프라인 기본 UI
- VAPID 기반 Web Push 알림 (브라우저 닫아도 수신)

### 3.7 YOLO11 다중 인원 추적

- **YOLO11s-pose** 모델로 N명 동시 감지 및 자세 추정
- **ByteTrack** 알고리즘으로 인물별 ID 추적 (프레임 간 일관성 유지)
- 인원별 개별 상태 관리 (각자 독립적인 낙상 상태 추적)
- 실시간 추적 ID 표시 및 시각화

### 3.8 AI 하이브리드 낙상 감지 (V4 최종)

- **GRU ONNX 딥러닝 모델 (주 판정)**: 30프레임 시퀀스 기반 GRU 분류기, AIHub 665,574 시퀀스 학습 (1.9MB)
- **13개 규칙 조건 (보조 판정)**: C1-C4 기립, C5-C7 착석, N1-N6 강화 규칙
- **EMA 비대칭 스무딩**: 공격 알파 0.6 / 감쇠 알파 0.3으로 오탐 억제
- **V4 성능**: Recall 95.2% / Precision 94.6% / F1 94.9 (424개 영상 검증)
- 지속적인 학습 데이터 확장으로 모델 개선 가능

### 3.9 WebRTC 영상 스트리밍

- **go2rtc** 기반 WHEP 프로토콜 WebRTC 스트리밍
- 저지연 실시간 영상 전송 (< 500ms)
- MJPEG 폴백 지원 (WebRTC 미지원 환경 대응)
- 다중 클라이언트 동시 시청 지원

### 3.10 통계 대시보드

- **일별/시간대별/인원별/요약 카드**: Recharts 라이브러리 기반 시각화
- **요약 카드**: 총 이벤트 수, 평균 응답 시간, 주요 위험 시간대 등
- **이벤트 히스토리**: 필터링 및 검색 기능
- 데이터 기반 패턴 분석으로 예방 조치 수립

### 3.11 EMR/FHIR 연동

- **HL7 FHIR R4** 표준 준수
- **Observation 리소스** 자동 생성 및 전송
- 낙상 이벤트를 의료 기록으로 통합 관리
- EMR 시스템과의 양방향 연동 지원

### 3.12 Safe-Zone 관리

- **Canvas 기반 폴리곤 에디터**로 안전/위험 구역 설정
- 실시간 구역 침범 감지 및 알림
- 구역별 경보 레벨 조정 가능
- 시설별 맞춤형 공간 설정

## 5. 차별성 및 특수성

### 5.1 경쟁 제품 비교

| 기능 | SENTIO | 웨어러블 센서 | 레이더 감지 | 기존 CCTV AI |
|------|-----------|-------------|-----------|------------|
| 착용 필요 | **불필요** | 필요 | 불필요 | 불필요 |
| 감지 정확도 | **매우 높음 (AI 앙상블: 규칙+ML)** | 중간 | 낮음 | 중간 |
| 실시간 영상 | **지원** | 미지원 | 미지원 | 지원 |
| 프라이버시 보호 | **3단계 모드** | N/A | N/A | 없음 |
| 설치 비용 | **낮음 (웹캠)** | 중간 | 높음 | 높음 |
| 다인원 추적 | **지원 (YOLO11+ByteTrack)** | 개별 착용 | 제한적 | 제한적 |
| 웹 기반 | **PWA** | 전용 앱 | 전용 장비 | 전용 소프트웨어 |
| 알림 방식 | **대시보드+Push** | 알림만 | 알림만 | CCTV 모니터 |
| AI 앙상블 | **규칙 60% + ML 40%** | 없음 | 단일 방식 | 단일 방식 |
| EMR 연동 | **FHIR R4** | 없음 | 없음 | 제한적 |

### 5.2 SENTIO만의 차별점

1. **비접촉 AI 감지**: 환자가 아무것도 착용하지 않아도 됨 (치매 환자 특히 유리)
2. **AI 앙상블 (규칙 4조건 60% + Transformer ML 40%)**: 단일 방식 대비 오탐률 대폭 감소
3. **2단계 점진적 알림**: 불필요한 긴급 알림 최소화
4. **3단계 프라이버시 모드**: 개인정보보호법 준수 용이
5. **웹 기반 PWA**: 별도 설치 없이 모든 기기에서 접근
6. **오픈소스 기반**: MediaPipe 활용으로 라이선스 비용 없음
7. **CPU 전용**: GPU 서버 없이도 실시간 분석 가능
8. **즉시 배포**: Docker Compose 한 줄로 전체 시스템 배포
9. **YOLO11 기반 다중 인원 추적**: 동시 N명 감지로 대규모 시설 대응
10. **WebRTC 저지연 영상 + MJPEG 폴백**: 다양한 환경 지원
11. **HL7 FHIR R4 표준 EMR 연동**: 의료 기록 통합 관리
12. **통계 대시보드**: 데이터 기반 의사결정 지원
13. **IoT 확장 대응**: 향후 스마트 경광등, IoT 센서 연동 인터페이스 내장
14. **다중공간 관리**: 복도, 대기실, 병실 등 공간별 카메라 배정 및 독립 모니터링/통계/리포트

## 7. 기대 효과

### 7.1 정량적 효과

| 효과 | 수치 |
|------|------|
| 낙상 발견 시간 단축 | 평균 30분 → **즉시** (실제 낙상) / **5초 이내** (전조) |
| 골든타임 내 대응률 | 40% → **95%+** |
| 야간 모니터링 인력 | 2~3명 → **AI + 1명** |
| 낙상 관련 입원 비용 절감 | **연간 30~50%** |
| 의료 분쟁 리스크 | **대폭 감소** (실시간 기록) |

### 7.2 정성적 효과

- **환자 안전**: 24시간 끊김 없는 모니터링
- **간호사 업무 부담 경감**: AI가 1차 감시, 간호사는 직접 케어에 집중

### 10.3 PoC (무료 실증) 프로그램

B2B 의료 시설 영업에서 핵심이 되는 **PoC(Proof of Concept) 무료 실증** 프로그램:

| 단계 | 기간 | 내용 | 비용 |
|------|------|------|------|
| **PoC 신청** | - | 시설 환경 분석, 카메라 위치 사전 조사 | 무료 |
| **PoC 실증** | 2~4주 | Community 요금제 기능 전체 제공 + 기술 지원 | **무료** |
| **PoC 결과 리포트** | PoC 종료 후 | 감지 정확도, 이벤트 통계, ROI 분석 보고서 | 무료 |
| **정식 도입** | 계약 후 | Professional/Enterprise 전환, 확장 설치 | 유료 |

- **PoC 조건**: 카메라 1~2대, 2~4주 운영, 기술 지원 포함
- **PoC 목표**: 실제 환경에서의 감지 정확도 검증, 의료진 피드백 수집
- **전환율 목표**: PoC → 정식 도입 **60%+** (업계 평균 30% 대비 2배)

### 10.4 도입 프로세스

```
1. 문의/상담 → 2. 시설 환경 분석 → 3. PoC 무료 실증 (2~4주)
       → 4. PoC 결과 리포트 → 5. 계약 → 6. 설치/교육 → 7. 운영 + 지속 지원
```

### 11.2 YOLO11 vs YOLOv8 비교 및 선택 근거

#### 성능 비교표

| 지표 | YOLOv8 | YOLO11 | 차이 | 의미 |
|------|--------|--------|------|------|
| mAP (COCO) | 기준선 | +1~2% | 정확도 향상 | 겹치는 환자, 작은 객체(낙상) 감지 개선 |
| CPU 추론 속도 | 기준선 | **~30% 빠름** | 중요 | **요양병원 저사양 PC에서 실시간 처리 가능** |
| 파라미터 수 | 100% | **78%** | **22% 감소** | **메모리 절약 + MediaPipe 동시 실행** |
| GPU 지연 | 기준선 | 더 낮음 | 소폭 개선 | 고사양 PC에서 추가 최적화 |
| C2PSA 모듈 | 없음 | **추가** | 신규 | **중첩 객체(겹친 환자) 감지 향상** |
| C3k2 블록 | 없음 | **추가** | 신규 | 더 효율적인 특징 추출 |

#### YOLO11 선택 이유

1. **CPU 30% 속도 향상** → GPU 없는 요양병원 일반 PC에서 실시간 처리 가능
   - 대부분 요양병원은 고사양 서버 구축 불가능
   - 기존 CCTV 인프라(저사양 NVR) 활용 가능

2. **22% 파라미터 감소** → MediaPipe 동시 실행 시 메모리 여유 확보
   - YOLO11s-pose 모델 (~19.4MB, Small 변형)
   - 동시에 MediaPipe 33점 분석으로 정확도 강화 가능

3. **C2PSA 공간 주의 모듈** → 겹치는 환자/작은 객체(바닥에 넘어진 환자) 감지 향상
   - 병실에서 보호자와 환자가 겹칠 때 정확한 감지
   - 좁은 공간에서의 낙상 감지율 향상

4. **C3k2 블록** → 더 효율적인 특징 추출로 정확도+속도 동시 개선

5. **API 호환성** → ultralytics 라이브러리 동일, YOLOv8 코드와 100% 호환
   - 기존 구현 코드 변경 최소화

6. **small 변형(yolo11s-pose) 최적화** → CPU 전용 실시간 처리에 최적
   - 경량 모델(~19.4MB)로 엣지 디바이스(Jetson Nano, Raspberry Pi) 확장 가능

**참고**: 2026년 1월 YOLO26도 출시되었으나 아직 초기 단계이며, YOLO11은 충분한 검증과 안정성을 갖춘 검증된 솔루션입니다.
