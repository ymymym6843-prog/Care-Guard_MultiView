## 슬라이드 3: 솔루션 소개 — SENTIO란?

**제목:** SENTIO가 해결합니다

**핵심 한줄:** 기존 CCTV에 소프트웨어만 추가하면 완성되는 AI 낙상 감지 시스템

**동작 흐름 (3단계 다이어그램):**
1. **기존 CCTV 영상** → AI가 실시간 분석
2. **낙상 감지** → 환자가 넘어지는 순간 자동 감지 (3초 이내)
3. **즉시 알림** → 간호사에게 알림 전송, 빠른 대응

**차별점:**
- 별도 센서나 웨어러블 불필요
- 기존 CCTV 인프라 그대로 활용
- 프라이버시 보호 Blur 모드 지원

## 슬라이드 4: 기술 아키텍처

**제목:** 어떻게 작동하는가?

**파이프라인 다이어그램:**

```
CCTV 영상 입력
    ↓
YOLOv8 (사람 감지 + 포즈 추정)
    ↓
33개 관절점 추출 (MediaPipe Pose)
    ↓
규칙 기반 1차 판단          ML 기반 2차 판단
(각도/속도/높이 임계값)     (FallDetectionTransformer)
    ↓                         ↓
         2단계 융합 판정
              ↓
      최종 낙상 판정 & 알림
```

**핵심 기술:**
- **YOLOv8**: 실시간 사람 감지 및 포즈 추정
- **MediaPipe Pose**: 33개 관절점 추출
- **FallDetectionTransformer**: 시퀀스 기반 ML 모델
- **2단계 감지**: 규칙 기반 + ML 기반 이중 검증으로 오탐 최소화

## 슬라이드 7: 성능을 쉽게 설명하면?

**제목:** 쉽게 말하면?

**시각적 비유 3개 (10x10 도트 그리드 형태로 표현):**

1. **감지율 95.2%**
   - 실제 넘어진 100명 중 95명을 감지
   - 초록 점 95개 + 빨간 점 5개
   - 놓치는 경우는 5명뿐

2. **정밀도 94.6%**
   - 알림 100건 중 95건이 진짜 낙상
   - 초록 점 95개 + 노란 점 5개
   - 거짓 알림은 5건뿐

3. **F1 Score 94.9**
   - 감지율과 정밀도의 조화 평균
   - 둘 다 높아야 높은 점수 — 균형 잡힌 시스템
   - 진행 바 94.9% 채움

## 슬라이드 8: 다각도 감지

**제목:** 어떤 각도에서든 정확하게

**2x2 그리드 이미지 레이아웃:**
- 전방 낙상 (Fall-Forward) — 감지 성공
- 후방 낙상 (Fall-Backward) — 감지 성공
- 측면 낙상 (Fall-Sideways) — 감지 성공
- 정상 행동 (Normal Activity) — 정상 판정

**메시지:** 정상 행동은 정상으로, 낙상만 정확히 구별합니다.
