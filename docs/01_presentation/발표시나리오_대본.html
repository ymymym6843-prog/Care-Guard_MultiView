안녕하세요, SENTIO AI를 발표하겠습니다.

SENTIO는 기존 CCTV에 AI를 연결해서, 환자가 넘어지는 순간 간호사에게 즉시 알려주는 시스템입니다.

424개 실제 영상으로 테스트한 결과, 낙상 20건 중 19건을 자동으로 감지합니다.

지금부터 왜 이 시스템이 필요한지, 실제로 어떻게 동작하는지 보여드리겠습니다.

낙상은 의료사고 원인 2위이고, 골절 → 장기 입원 → 의료비 증가 → 법적 책임까지 이어집니다.

그래서 저희가 만든 것이 SENTIO AI입니다.

셋째, 환자 프라이버시를 보호합니다. 원본 영상 대신 관절점만 분석하기 때문에 환자 얼굴이나 신체가 노출되지 않습니다.

넷째, 대기실에 여러 환자가 있어도 각각 따로 추적합니다. 한 명이 넘어지면 그 환자만 정확히 경고합니다.

실제 AI 감지 데모
~2분

GIF 4개가 2x2 그리드로 자동 재생 (전방/후방/측면 낙상 + 정상 행동)

설명만으로는 와닿지 않으실 테니, 실제 AI가 동작하는 모습을 보여드리겠습니다.

화면에 4가지 상황을 동시에 보여드리고 있습니다.
1
좌상: 전방 낙상 (97% 감지율)
앞으로 넘어지는 순간, 초록 박스가 빨간 박스로 바뀌면서 팝업 알림이 뜹니다. "낙상이 감지되었습니다" 팝업이 보이시죠.
2
우상: 후방 낙상 (99% 감지율)
뒤로 넘어지는 건 가장 위험한 유형인데요, 이것도 즉시 감지합니다. 머리 부상 위험이 높아서 가장 빠른 대응이 필요합니다.
3
좌하: 측면 낙상 (91% 감지율)
옆으로 넘어지는 경우입니다. 가장 감지하기 어려운 유형이지만, AI가 움직임 패턴을 분석해서 잡아냅니다.
4
우하: 정상 행동 (오탐 없음)
정상적으로 걷고 앉는 상황에서는 알림이 발생하지 않습니다. 정상 행동은 정상으로 판단한다는 걸 확인하실 수 있습니다.

예상 Q&A 준비

기존 CCTV와 호환되나요?
네, 대부분의 IP 카메라와 바로 연결됩니다. 현재 쓰고 계신 CCTV를 별도 교체 없이 그대로 사용하시면 됩니다. RTSP 주소만 등록하면 즉시 모니터링이 시작됩니다.
고성능 컴퓨터(GPU)가 필요한가요?
아닙니다. 일반 사무용 PC에서도 동작하도록 ONNX Runtime으로 최적화했습니다. GPU가 있으면 더 빠르지만, 없어도 정확도는 완전히 동일합니다. CPU 환경에서도 카메라 3대 동시 처리가 가능합니다.
프라이버시 법적 문제는?
기본 스켈레톤 모드에서는 원본 영상을 저장하지 않고, AI가 분석하는 건 관절 좌표 — 숫자 데이터입니다. 환자 얼굴이나 신체가 어디에도 기록되지 않습니다. 3가지 프라이버시 모드(스켈레톤/블러/원본)를 제공하고, 원본 모드는 관리자만 접근 가능합니다.
잘못된 알림이 많으면 업무에 방해되지 않나요?
알림이 울렸을 때 95%는 실제 낙상입니다(정밀도 94.6%). 잘못된 알림은 주로 '빠르게 앉기', '물건 줍기' 같은 동작에서 발생합니다. Safe-Zone 기능으로 침대/소파 영역에서는 알림을 자동 억제할 수 있어 오탐을 더 줄일 수 있습니다.
옆으로 넘어지는 건 감지되나요?
측면 낙상도 91% 감지합니다. 카메라를 여러 각도로 배치하시면 사각지대가 줄어서 감지율이 더 올라갑니다. 3대 카메라 동시 운영 시 전방향 커버가 가능합니다.
도입 전에 테스트할 수 있나요?
네, 2~4주 무료 PoC(실증)를 제공합니다. 실제 병원 환경에서 효과를 직접 확인하신 후에 도입을 결정하시면 됩니다. PoC 후 감지 정확도와 알림 통계 리포트를 드립니다.
가격이 어떻게 되나요?
기존 센서 솔루션(Vayyar Care 등)은 방당 50만원+인데, SENTIO는 기존 CCTV 활용으로 초기 비용 0원, 월 30만원부터 시작합니다. Pro(카메라 5대)는 월 70만원입니다.
AI가 어떻게 넘어지는 걸 알아내나요? (기술 질문)
33개 관절의 움직임을 실시간 추적해서, 머리-엉덩이 역전, 수직 하강 속도 등 13가지 물리 규칙을 체크합니다. 동시에 66만 건으로 학습한 GRU 딥러닝 모델이 시계열 패턴을 분석합니다. 두 가지를 앙상블해서 정확도를 높이는 하이브리드 방식입니다.
경쟁사와 비교하면? (심층 질문)
기존 센서 기반(Vayyar Care)은 전용 장비 필요 + 방당 50만원+, 다인 추적 불가. 기존 CCTV AI 서비스는 대부분 정확도를 공개하지 않습니다. SENTIO는 424개 실제 영상으로 검증한 F1 94.9를 투명하게 공개하고, 기존 CCTV만으로 도입 가능하며, 동시 N명 개별 추적이 되는 유일한 솔루션입니다.
