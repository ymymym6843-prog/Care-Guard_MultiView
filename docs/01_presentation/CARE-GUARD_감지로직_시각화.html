어떻게 AI가 낙상을 감지하는지, 한눈에 이해하기

V4 최종 확정 | F1 94.9 | 424개 영상 검증

🎯 핵심 요약: 이렇게 동작합니다

카메라 영상에서 사람의 관절을 찾고, 관절의 움직임 패턴을 AI가 분석하여 낙상 여부를 판단합니다. 마치 경험 많은 간호사가 환자를 지켜보는 것과 비슷하지만, 24시간 쉬지 않고 봅니다.

📷 영상 입력 & 관절 추출
카메라 영상에서 YOLO11이 사람을 찾고, 각 사람의 17개 관절점(머리, 어깨, 팔꿈치, 손목, 엉덩이, 무릎, 발목)을 추출합니다. 이 17개 점을 33개 점으로 확장하여 더 정밀하게 분석합니다.
사람의 몸에 17개의 LED를 붙여서 움직임을 추적하는 것과 같습니다. 어두운 방에서 LED만 보고도 그 사람이 서있는지, 넘어졌는지 알 수 있죠.
🧍 자세 분류: 서있나? 앉았나? 누웠나?
관절 위치를 바탕으로 현재 기립(Standing), 착석(Sitting), 누움(Lying) 중 어떤 자세인지 파악합니다. 자세에 따라 낙상 판정 기준이 달라집니다.
서 있다가 갑자기 누운 건 위험하지만, 원래 침대에 누워있던 건 정상이죠. 자세를 먼저 파악해야 "비정상적인 변화"를 구별할 수 있습니다.
📐 규칙 기반 점수 (13개 조건 체크)
경험적으로 알려진 낙상 특징 13가지를 체크합니다. 예: "머리가 엉덩이보다 낮아졌는가?", "급격히 떨어졌는가?", "몸이 수평이 되었는가?" 등. 각 조건이 충족되면 점수가 올라갑니다.
의사의 체크리스트와 같습니다. "열이 나나요?" "기침을 하나요?" "두통이 있나요?" — 여러 증상을 종합해서 진단하듯이, 13가지 낙상 징후를 종합합니다.
🧠 AI(GRU) 딥러닝 점수
최근 30프레임(약 1초)의 관절 움직임 패턴을 GRU 신경망이 분석합니다. AIHub의 66만 개 학습 데이터로 훈련된 모델이 "이 움직임이 낙상과 얼마나 비슷한지" 0~1 사이의 확률로 판단합니다.
66만 번의 낙상 영상을 본 전문가와 같습니다. "이 움직임 패턴... 전에 봤던 낙상이랑 95% 비슷해!" 라고 판단하는 것이죠.
⚖️ EMA 스무딩 & 점수 결합
규칙 점수와 ML 점수를 결합하고, EMA(지수이동평균)로 부드럽게 만듭니다. 비대칭 스무딩: 위험 신호는 빠르게 반응(0.6), 안전 복귀는 천천히(0.3). 최종 결합 점수가 0.5 이상이면 낙상으로 1차 판정합니다.
화재 경보기와 비슷합니다. 연기가 나면 즉시 울리지만(빠른 반응), 연기가 사라져도 잠시 더 경계합니다(느린 복귀). 한 번 깜빡한다고 바로 울리지 않아서 오경보를 줄입니다.
🛡️ 오탐 방지 필터 (5단계)
"낙상처럼 보이지만 사실 아닌 것"들을 걸러냅니다. 물건 줍기, 천천히 눕기, 정상적으로 앉기 등 일상 동작을 낙상과 구별합니다. 추가로 "서서+상체 직립+규칙 점수 낮음"이면 ML이 높아도 취소합니다.
CCTV 보안관이 경보가 울렸을 때 화면을 한 번 더 확인하는 것과 같습니다. "어, 저건 그냥 물건 줍는 거잖아" 하고 오경보를 취소하는 과정입니다.
🔢 연속 프레임 확인
한 프레임만 보고 판단하면 노이즈에 취약합니다. 보통 2프레임 연속 낙상으로 판정되어야 최종 감지합니다. 단, 점수가 매우 높으면(≥0.90 또는 ML≥0.60+점수≥0.70) 1프레임으로 즉시 감지합니다.
의사가 "한 번 이상하다고 바로 진단하지 않고, 검사를 두 번 해보자"는 것과 같습니다. 하지만 증상이 매우 명확하면 한 번에 진단합니다.
🚨 최종 판정 & 알림
모든 검증을 통과하면 낙상 확정! 확률 기반 상태 머신이 SAFE → WARNING(0.50+) → DANGER(0.70+, 0.5초 지연)로 전환되며, 즉시 알림이 발송됩니다. WARNING 3초 최소 유지 + DANGER 5초간 정상 상태가 유지되어야 해제됩니다.
119에 전화하기 전에 여러 번 확인하고, 확실하면 즉시 출동 요청하는 것과 같습니다. 출동 후에도 5초간 상황을 지켜보다가, 환자가 스스로 일어나면 해제합니다.

📋 13개 규칙 조건: 낙상의 징후들

사람이 넘어질 때 나타나는 신체적 특징을 13가지로 정리했습니다. 마치 의사의 진단 체크리스트처럼, 여러 징후가 동시에 나타나면 낙상일 확률이 높습니다.

코드 무엇을 보나? 쉬운 설명 비중
C1 머리-엉덩이 역전 머리가 엉덩이보다 낮아짐 → 몸이 뒤집힌 상태 35%
C2 급격한 하강 머리 높이가 갑자기 뚝 떨어짐 (0.3초 이내) 25%

C5 전방 고꾸라짐 (착석) 앉은 상태에서 머리가 무릎 아래로 떨어짐 +25%

왜 13개나 필요할까요?

낙상은 한 가지 방식으로만 일어나지 않습니다. 앞으로 넘어지기, 뒤로 넘어지기, 옆으로 미끄러지기, 의자에서 떨어지기 등 다양한 상황이 있어요. 하나의 조건만으로는 "물건 줍기"와 "앞으로 넘어지기"를 구별할 수 없습니다. 여러 조건이 동시에 만족될수록 낙상 확률이 높아집니다.

📊 EMA 비대칭 스무딩: 빠르게 반응, 천천히 복귀

AI의 점수를 그대로 사용하면 노이즈(잡음)에 의한 오경보가 많아집니다. EMA(지수이동평균)로 점수를 부드럽게 만들되, 위험할 때는 빨리, 안전할 때는 천천히 반응하도록 설계했습니다.

왜 비대칭일까요?

화재 감지기를 생각해보세요. 연기가 감지되면 즉시 경보를 울려야 합니다 (빠른 반응). 하지만 연기가 조금 줄었다고 바로 경보를 끄면 안 됩니다 (느린 복귀). 실제 화재는 연기가 잠깐 줄었다가 다시 늘어날 수 있기 때문이죠. 낙상도 마찬가지입니다 — 넘어지는 순간을 빠르게 잡되, 혹시 아직 넘어지는 중일 수 있으니 경계를 천천히 풀어야 합니다.

🛡️ 오탐 방지: "이건 낙상이 아닌데?" 걸러내기

일상 동작 중에 낙상과 비슷해 보이는 것들이 많습니다. 이런 "가짜 낙상"을 걸러내는 5가지 필터를 적용합니다. 오경보가 너무 많으면 간호사가 알림을 무시하게 되므로(알림 피로), 오탐 방지가 매우 중요합니다.

🔍

필터 1: 물건 줍기 감지

머리가 낮아지고(C1) 급격히 내려갔지만(C2), 몸이 수평이 아닌(C3 X) 경우 → 물건 줍기

"바닥에 떨어진 약을 줍는 환자" → 낙상 아님!
🛏️

필터 2: 의도적 눕기 감지

몸이 수평(C3)이 되었지만, 급격한 가속도(N1)나 낙하 패턴(N6)이 없는 경우 → 천천히 누운 것

"침대에 천천히 눕는 환자" → 낙상 아님!
🪑

필터 3: 정상 착석 감지

서있다가 앉을 때 높이가 떨어지지만(C2), 가속도나 낙하 패턴이 없는 경우 → 정상 착석

"의자에 앉으려는 환자" → 낙상 아님!
🤸

필터 4: 서서 하는 동작 감지

서있는 상태에서 급격한 가속도(N1) 없이 머리만 낮아지는 경우 → 스트레칭이나 운동

"스트레칭하는 환자" → 낙상 아님!
🧍‍♂️

필터 5: Standing FP 필터 (V4 신규)

서있고 + 상체가 직립(>75°) + 규칙 점수가 낮고(<0.20) + 최종 점수가 극히 높지 않은(<0.90) 경우 → 감지 취소

"꼿꼿이 서서 팔만 흔드는 환자" → ML이 잠깐 높게 나와도 무시!

Recall이란?

"실제 낙상을 몇 %나 잡았나?"

100명이 넘어졌을 때, 그 중 95명을 감지했다면 Recall 95.2%. 요양병원에서 가장 중요한 지표입니다 — 낙상을 놓치면 환자가 위험하니까요.

20건 중 19건 감지! 놓치는 비율을 최소화하는 것이 핵심입니다.

Precision이란?

"알림이 울렸을 때, 진짜 낙상인 확률"

100번 알림이 울렸을 때, 95번이 실제 낙상이라면 Precision 94.6%. 오경보가 너무 많으면 간호사가 알림을 무시하게 되므로 중요합니다.

양치기 소년 효과 방지! 경보의 95%가 진짜여야 신뢰할 수 있습니다.

F1-Score란?

"Recall과 Precision의 균형 점수"

둘 다 높아야 높은 점수가 나옵니다. Recall만 높고 Precision이 낮으면 (혹은 그 반대면) F1은 낮아집니다. 두 마리 토끼를 다 잡았는지를 보여주는 종합 지표입니다.

학교 성적으로 비유하면, 국어 90 + 수학 95 → 종합 92.5점

왜 FP와 FN 모두 중요한가?

FP(오탐) = 알림 피로: 가짜 알림이 많으면 진짜 때도 무시하게 됨

FN(미탐) = 안전 위협: 실제 낙상을 놓치면 환자가 위험

의료 현장에서는 FN이 더 치명적이므로 Recall 우선!

FP는 "헛발질", FN은 "놓침". 놓치는 게 더 위험합니다.

전방/후방 낙상은 머리 높이가 급격히 변하지만, 측면 낙상은 옆으로 쓰러지기 때문에 카메라 각도에 따라 높이 변화가 적게 보일 수 있습니다. V4에서 착석 임계값 조정과 연속프레임 완화로 91%까지 개선했습니다.
