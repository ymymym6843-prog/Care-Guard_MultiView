발표 후 질의응답 대비 — 9개 질문 + 추가 대응 팁
일반 질문 (높은 확률)
Q. 기존 CCTV와 바로 연결되나요?
네, IP 카메라면 대부분 바로 됩니다. 지금 쓰시는 CCTV 교체 없이 RTSP 주소만 등록하면 바로 모니터링 시작돼요.
Q. 비싼 GPU 서버가 필요한 거 아닌가요?
아닙니다. 일반 사무용 PC에서도 돌아가도록 ONNX로 최적화했어요. GPU 없어도 정확도는 똑같고 카메라 3대 동시 처리까지 가능합니다.
Q. 환자 영상이 저장되면 프라이버시 문제 아닌가요?
기본 모드에서는 원본 영상을 저장하지 않아요. AI가 보는 건 관절 좌표(숫자)뿐이라 얼굴이나 신체가 안 남습니다. 스켈레톤/블러/원본 3가지 모드 중 선택 가능해요.
Q. 거짓 알림이 많으면 오히려 업무 방해 아닌가요?
알림이 울렸을 때 95%는 실제 낙상이에요 (정밀도 94.6%). Safe-Zone 기능으로 침대/소파 영역은 알림을 자동 억제할 수 있어요.
Q. 옆으로 넘어지는 것도 감지되나요?
네, 측면 낙상도 91% 감지해요. 카메라를 여러 각도로 배치하면 전방향 커버가 가능합니다.
Q. 도입 전에 테스트해볼 수 있나요?
2~4주 무료 PoC(실증)를 제공해요. 직접 써보시고 결정하시면 됩니다. PoC 후 감지 정확도와 알림 통계 리포트도 드려요.
Q. 가격은 어떻게 되나요?
기존 센서 솔루션은 방당 50만원+인데, SENTIO는 초기 비용 0원, 월 30만원부터. Pro(카메라 5대)는 월 70만원이에요.
기술 심화 질문
Q. AI가 어떤 원리로 넘어지는 걸 감지하나요?
YOLO11이 17개 관절 좌표를 실시간 추출하고, 머리-엉덩이 역전·수직 하강 속도 등 물리 규칙을 체크합니다. 동시에 66만 건으로 학습한 GRU 딥러닝 모델이 시계열 패턴을 분석해요. 이 둘을 앙상블하는 하이브리드 방식입니다.
Q. 경쟁사 대비 장점이 뭔가요?
레이더 센서(Vayyar 등)는 전용 장비 필요 + 방당 50만원+ + 다인 추적 불가. 기존 CCTV AI 서비스는 정확도 비공개가 대부분. SENTIO는 F1 94.9를 투명 공개, 기존 CCTV만으로 도입, 동시 N명 개별 추적이 되는 점이 차별점입니다.
