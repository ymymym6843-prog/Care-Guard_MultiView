## 요양병원 낙상 감지 시스템

> 20건의 낙상 중 19건을 자동 감지 | 424개 실제 영상으로 검증

## 1. 왜 필요한가?

### 낙상 사고, 얼마나 심각한가

| 통계 | 수치 |
|------|------|
| 65세 이상 연간 낙상률 | 28~35% |
| 의료사고 원인 순위 | **2위** |
| 대기실/복도 낙상 비율 | 전체의 47% |
| 간호사 1인당 담당 환자 | 20~30명 |

### 현장의 어려움
- 간호사가 대기실과 복도를 **24시간 지켜보는 것은 현실적으로 불가능**
- 낙상 발생 → 골절 → 입원 연장 → 의료비 증가 → 법적 책임
- **발견이 늦을수록 피해가 커짐** — "골든타임"이 핵심

## 2. SENTIO는 무엇인가?

### 한 줄 요약
> 기존 CCTV에 AI를 연결하면, 환자가 넘어지는 순간 간호사에게 즉시 알려줍니다.

### 4가지 핵심 가치

| # | 가치 | 병원에 주는 이점 |
|---|------|-----------------|
| 1 | **기존 CCTV 그대로 활용** | 새로운 장비 구매 불필요, 바로 도입 |
| 2 | **AI 실시간 감지** | 넘어지는 순간 자동 알림 → 빠른 대응 |
| 3 | **프라이버시 보호** | 환자 얼굴/신체 노출 없이 관절점만 분석 |
| 4 | **여러 환자 동시 추적** | 대기실에 여러 명이 있어도 개별 모니터링 |

### SENTIO vs 기존 방식

| 항목 | 기존 CCTV | 기존 센서 솔루션 | **SENTIO** |
|------|----------|----------------|----------------|
| 낙상 감지 | 사람이 직접 확인 | 별도 센서 필요 | **AI 자동 감지** |
| 추가 장비 | - | 1,000만원+ | **불필요** |
| 프라이버시 | 원본 저장 | 해당 없음 | **관절점만 처리** |
| 여러 명 추적 | 불가 | 제한적 | **동시 추적 가능** |

## 3. 어떻게 동작하나?

### 동작 과정 (간단 요약)

```
  CCTV 영상      →    AI가 사람 인식     →    낙상 여부 판단    →    즉시 알림
 (기존 카메라)      (관절 움직임 추적)     (이상 패턴 감지)     (소리+화면+푸시)
```

### AI가 하는 일

1. **사람 찾기** — 영상에서 사람을 자동으로 찾아냅니다
2. **관절 추적** — 어깨, 엉덩이, 무릎 등 주요 관절의 움직임을 추적합니다
3. **패턴 분석** — "머리가 급격히 내려갔는가?", "몸이 수평으로 변했는가?" 등을 판단합니다
4. **위험 판정** — 66만 건의 학습 데이터로 훈련된 AI가 낙상 확률을 계산합니다
5. **즉시 알림** — 위험 감지 시 소리, 화면 경고, 스마트폰 푸시 알림을 동시에 보냅니다

### 알림 체계

| 단계 | 상태 | 의미 | 알림 방식 |
|------|------|------|-----------|
| 1단계 | 정상 (녹색) | 이상 없음 | 모니터링만 |
| 2단계 | 주의 (노랑) | 이상 징후 감지 | 화면 경고 |
| 3단계 | **위험 (빨강)** | **낙상 감지** | **소리 + 화면 + 푸시 + 음성 안내** |

## 6. 프라이버시는 어떻게 보호하나?

### 3가지 영상 모드

| 모드 | 화면에 보이는 것 | 원본 영상 저장 |
|------|----------------|---------------|
| **스켈레톤 (기본)** | 검정 배경 + 관절점만 | 저장 안 함 |
| **블러** | 모자이크 처리된 영상 | 저장 안 함 |
| **원본** | 관리자 전용 원본 | 저장 안 함 |

### 핵심 원칙
- **원본 영상은 어떤 모드에서도 저장하지 않습니다**
- AI는 관절 좌표(숫자)만 분석 — 얼굴, 신체 이미지를 기록하지 않음
- 사고 발생 시에만 관절 좌표 데이터를 자동 보관 (사고 분석용)
- 개인정보보호법 준수 설계

## 예상 Q&A

### Q1. "기존 CCTV와 호환되나요?"
> 대부분의 IP 카메라(CCTV)와 바로 연결됩니다. 별도 교체 없이 사용 가능합니다.

### Q2. "GPU(고성능 컴퓨터)가 필요한가요?"
> 필요하지 않습니다. 일반 사무용 PC에서도 동작하도록 최적화되어 있습니다. 고성능 컴퓨터가 있으면 더 빠르게 처리되지만, 없어도 정확도는 동일합니다.

### Q3. "프라이버시 법적 문제는 없나요?"
> 스켈레톤 모드에서는 원본 영상을 저장하지 않고 관절 좌표(숫자)만 처리합니다. 개인정보보호법 준수 설계이며, 환자 얼굴이나 신체가 기록되지 않습니다.

### Q4. "잘못된 알림이 많으면 업무에 방해되지 않나요?"
> 알림의 95%가 실제 낙상입니다. 잘못된 알림은 주로 "빠르게 앉기", "물건 줍기" 등 낙상과 유사한 동작에서 발생하며, AI가 지속적으로 학습하여 줄여나갑니다.

### Q5. "옆으로 넘어지는 경우도 감지되나요?"
> 네, 측면 낙상도 91% 감지합니다. 카메라를 여러 대 배치하면 사각지대를 줄여 감지율을 더 높일 수 있습니다.

### Q6. "도입 전에 테스트해볼 수 있나요?"
> 2~4주 무료 PoC(실증)를 제공합니다. 실제 병원 환경에서 효과를 확인한 후 도입을 결정할 수 있습니다.

### Q7. "경쟁사 대비 가격이 어떤가요?"
> 기존 센서 솔루션은 초기 1,000만원 이상 투자가 필요합니다. SENTIO는 기존 CCTV를 활용하므로 초기 비용 0원, 월 30만원부터 시작합니다.

### 13가지 낙상 판정 규칙

**기하학 조건 7개**: 머리-엉덩이 역전(C1, 0.35), 수직 하강 속도(C2, 0.25), 체형 각도 수평화(C3, 0.20), 머리-발 높이비(C4, 0.10), 어깨-엉덩이 정렬(C5, 0.05), 중심 하강+자세(C6, 0.03), 관절 속도 이상(C7, 0.02)

**운동학 조건 6개**: 수직 가속도(N1), 보호 신전 반응(N2), 발목 간격(N3), 체형 각속도(N4), 서있는 상태 기울기(N5), 상하체 가속도 비율(N6)

### 오탐 방지 10단계 필터
