삽질의 기록

1개월간 마주한 주요 트러블슈팅 사례들입니다.

🔴 COCO→MediaPipe 변환 누락

문제: YOLO(COCO 17점) → FallDetector(MediaPipe 33점) 형식 불일치
증상: KeyError, IndexError — 키포인트 인덱스 매핑 오류
해결: coco_to_mediapipe_33() 변환 어댑터 구현
# KeypointAdapter - COCO 17점 → MediaPipe 33점 for coco_idx, mp_idx in COCO_TO_MP.items(): mp_landmarks[mp_idx] = coco_kpts[coco_idx]

🟡 pydantic-settings 싱글턴

문제: 테스트 간 settings 상태가 공유되어 오염
증상: 개별 테스트 성공, 전체 실행 시 실패
해결: settings 직접 패치 + tearDown에서 복원
# setUp: 상태 저장 → tearDown: 복원 original = settings.DEBUG settings.DEBUG = False # 테스트용

🟣 MJPEG 프레임 경합

문제: 다중 클라이언트 동시 MJPEG 요청 시 프레임 깨짐
증상: blank frame, EOFError, 이미지 손상
해결: threading.Lock으로 프레임 버퍼 동기화
self.frame_lock = threading.Lock() with self.frame_lock: frame = self.latest_frame.copy()

🔵 WebSocket 연결 끊김

문제: 30초 무활동 시 프록시/브라우저 타임아웃
증상: disconnected: 1006 (비정상 종료)
해결: 20초 간격 ping/pong 하트비트 구현
# 20초마다 heartbeat 전송 await ws.send_json({"type": "ping"}) await asyncio.sleep(20)

🔷 Docker GPU 드라이버

문제: Docker 컨테이너에서 CUDA 디바이스 미인식
증상: GPU 장착인데 CPU 폴백 모드로 실행
해결: nvidia-container-toolkit + docker runtime 설정
# docker-compose.yml deploy: resources: { reservations: { devices: [gpus: all] } }

🔶 EMA smoothing 튜닝

문제: alpha=0.3 반응 느림 / alpha=0.8 노이즈 과다
증상: FN 증가(느림) 또는 FP 증가(노이즈)
해결: alpha=0.5로 반응성/안정성 최적 균형
# EMA: 지수이동평균 필터 ema = 0.5 * current + 0.5 * previous if ema >= 0.70: return "DANGER"
💡 디버깅 원칙: 공식 문서 먼저 확인 | 디버거 적극 활용 | 작은 단위 테스트 작성 | 버전 호환성 체크 | 로그를 반드시 남겨라!

🔍 가장 오래 걸린 버그

COCO→MediaPipe 변환 누락 (3일). 키포인트 형식이 다르다는 걸 문서에서 못 찾아서 소스코드 직접 분석.

# 원인: YOLO는 17점, FallDetector는 33점 mp33 = coco_to_mediapipe_33(coco17)

WebSocket ping/pong (30분). 문제 재현 → 원인 파악 → 하트비트 추가로 해결.

EMA alpha 하나가 전체 성능 좌우. 체계적 실험의 중요성.

# 0.3(느림) → 0.5(균형) → 0.8(노이즈) ema = 0.5*curr + 0.5*prev # 최적!

벤치마크 인사이트

1. 측면(SY) 가장 어려움 — 91%

3. FN은 저화질/가림 환경 — 15건 중 9건

4. 후방(BY) 99%로 최고 성능

뒤로 넘어질 때 머리-엉덩이 역전+급격한 하강이 가장 뚜렷. 규칙+GRU 모두 높은 확신.

5. V5/V5.1 시도 → 개선 없음

안녕하세요, 석유민입니다. 물리치료사에서 AI 개발자가 된 사람입니다.

"왜 물리치료사가 AI를?" — 현장의 문제를 아는 사람이 가장 좋은 솔루션을 만듭니다. 요양병원에서 환자분들의 낙상과 발견 지연을 매일 목격했고, CCTV는 녹화만 할 뿐이었습니다. "이걸 AI가 대신 감시해주면 어떨까?" — 이 한 줄의 질문이 SENTIO의 시작이었습니다.

Python도, React도 몰랐지만 문제를 정확히 알고 있었습니다. 코딩 실력보다 중요한 건 해결하고 싶은 문제입니다. 도메인 지식이 있으면 AI가 풀어야 할 문제를 정확히 정의할 수 있고, 그것이 기술만 아는 개발자와의 차이를 만듭니다.
