V5 최신 | GRU + 11-Filter | 424개 영상 검증

🎯 핵심 요약: 이렇게 동작합니다

카메라 영상에서 사람의 관절을 찾고, 관절의 움직임 패턴을 AI가 분석하여 낙상 여부를 판단합니다. 마치 경험 많은 간호사가 환자를 지켜보는 것과 비슷하지만, 24시간 쉬지 않고 봅니다.

📷 영상 입력 & 관절 추출
카메라 영상에서 YOLO11s-pose 모델이 사람을 찾고, ByteTrack 트래커로 개인별 추적을 유지합니다. COCO 기준 17개 관절점(코, 눈, 귀, 어깨, 팔꿈치, 손목, 엉덩이, 무릎, 발목)을 추출합니다.

왜 33개로 확장하는가? GRU 낙상 감지 모델은 MediaPipe 33점 형식 (1, 30, 99) 텐서로 학습되었기 때문에, 입력 호환성을 위해 17점을 33점으로 변환해야 합니다. KeypointAdapter가 이 변환을 3단계로 수행합니다:
① 직접 매핑 — COCO 17개 점을 MediaPipe 33점 배열의 해당 위치에 1:1 복사
② 결측 보간 — COCO에 없는 나머지 16개 점(손가락, 발, 입 등)을 인접 관절에서 추정 (예: 손가락 → 손목 좌표 기준, 발 → 발목 좌표 기준)
③ 신뢰도 표시 — 보간된 점의 visibility를 50% 이하로 낮춰, 낙상 감지 로직이 "추정값"임을 인식할 수 있도록 구분
사람의 몸에 17개의 LED를 붙여서 움직임을 추적하는 것과 같습니다. AI 모델이 33개 LED 입력을 기대하므로, 나머지 16개는 근처 LED 위치로부터 "대략 이쯤에 있을 것"이라고 추정하여 채워넣습니다. 단, 추정된 LED는 "밝기를 낮춰" 실제 측정값과 구별합니다.
🧍 자세 분류: 서있나? 앉았나? 누웠나?
PostureClassifier가 관절 위치를 바탕으로 기립(Standing), 착석(Sitting), 누움(Lying) 중 어떤 자세인지 파악합니다. 5프레임 안정성 투표로 갑작스러운 자세 변화를 걸러내고, 착석 기준선은 처음 30프레임 누적 후 느린 EMA(α=0.02)로 점진적으로 갱신합니다.
서 있다가 갑자기 누운 건 위험하지만, 원래 침대에 누워있던 건 정상이죠. 자세를 먼저 파악해야 "비정상적인 변화"를 구별할 수 있습니다.
📐 규칙 기반 점수 (13개 조건 체크)
경험적으로 알려진 낙상 특징 13가지를 체크합니다. 예: "머리가 엉덩이보다 낮아졌는가?", "급격히 떨어졌는가?", "몸이 수평이 되었는가?" 등. 각 조건이 충족되면 점수가 올라갑니다. Enhanced 모드에서 가중치는 C1=35%, C2=25%, C3=25%.
주의: V5에서 규칙 점수는 참고용으로 계산되지만, 최종 점수에는 기여하지 않습니다 (아래 Step 5 참고).
의사의 체크리스트와 같습니다. "열이 나나요?" "기침을 하나요?" "두통이 있나요?" — 여러 증상을 종합해서 진단하듯이, 13가지 낙상 징후를 종합합니다.
🧠 AI(GRU) 딥러닝 점수
최근 30프레임(약 1초)의 관절 움직임 패턴을 GRU 신경망이 분석합니다. 입력 텐서는 (1, 30, 99) 형태이며, 4~5개 클래스(정상/전방낙상/후방낙상/측면낙상/전조충격)를 출력합니다. AIHub 665,574 시퀀스로 훈련된 모델 기준: Recall 84.3%, Precision 97.0%.
66만 번의 낙상 영상을 본 전문가와 같습니다. "이 움직임 패턴... 전에 봤던 낙상이랑 95% 비슷해!" 라고 판단하는 것이죠.
⚖️ 순수 ML 모드 & EMA 스무딩
V5에서는 순수 ML 모드를 사용합니다: rule_weight=0.0, ml_weight=1.0. 규칙 점수는 계산되지만 최종 점수에 0%만 기여하고, ML 점수가 100%를 결정합니다. 고신뢰(≥0.70) 및 중간신뢰(≥0.40) 낙상 유형에 대해 ML 부스트 메커니즘이 적용됩니다. 비대칭 EMA 스무딩: 위험 신호는 빠르게 반응(α=0.6), 안전 복귀는 천천히(α=0.3).
화재 경보기와 비슷합니다. 연기가 나면 즉시 울리지만(빠른 반응), 연기가 사라져도 잠시 더 경계합니다(느린 복귀). 한 번 깜빡한다고 바로 울리지 않아서 오경보를 줄입니다.
🛡️ 오탐 방지 필터 (11가지)
V5에서는 총 11가지 FP 방지 메커니즘이 적용됩니다. 물건 줍기, 천천히 눕기, 정상 착석 등 일상 동작을 낙상과 구별합니다. 특히 장기 누움 면제와 착석 ML 전용 차단 등 새로운 메커니즘이 추가되었습니다.
CCTV 보안관이 경보가 울렸을 때 화면을 한 번 더 확인하는 것과 같습니다. "어, 저건 그냥 물건 줍는 거잖아" 하고 오경보를 취소하는 과정입니다.
🔍 전조(Pre-Impact) 감지 — 3가지 독립 경로
낙상 직전의 위험 징후를 3가지 독립 경로로 감지합니다.
① 점수 경로: 결합 점수 ≥ 0.35 (낙상 임계값 미만)
② ML 경로: ML 원시값 ≥ 0.40
③ 규칙 경로: N4 무릎 좌굴 단독 발생
전조 감지 시 즉시 MONITORING 상태로 진입합니다. 이미 모니터링 중이면 실제 낙상 시 WARNING을 건너뜁니다.
의사가 비틀거리는 환자를 보고 "아직 넘어지지 않았지만, 곧 넘어질 수 있어" 하며 미리 준비하는 것과 같습니다.
🚨 최종 판정 & 5단계 알림 상태 머신
모든 검증을 통과하면 5단계 상태 머신이 알림 수준을 결정합니다. NORMAL → MONITORING(전조) → WARNING(0.50+) → DANGER(실제 낙상). DANGER 자동 해제: 회복 후 5초. 빠른 회복: 누운 상태 10프레임 + 기립 5프레임 + 점수<0.1. 프론트엔드 매핑: DANGER→"danger", WARNING→"warning", MONITORING/NORMAL→"safe".
119에 전화하기 전에 여러 번 확인하고, 확실하면 즉시 출동 요청하는 것과 같습니다. 출동 후에도 5초간 상황을 지켜보다가, 환자가 스스로 일어나면 해제합니다.

📋 13개 규칙 조건: 낙상의 징후들

사람이 넘어질 때 나타나는 신체적 특징을 13가지로 정리했습니다. 마치 의사의 진단 체크리스트처럼, 여러 징후가 동시에 나타나면 낙상일 확률이 높습니다. V5에서는 규칙이 참고 계산만 되며, ML 점수가 최종 판정을 주도합니다.

코드 무엇을 보나? 쉬운 설명 비중
C1 머리-엉덩이 역전 머리가 엉덩이보다 낮아짐 → 몸이 뒤집힌 상태 35%
C2 급격한 하강 머리 높이가 갑자기 뚝 떨어짐 (0.3초 이내) 25%
C3 수평 각도 어깨-엉덩이 축이 거의 수평 → 몸이 누운 형태 25%
C4 발목 위치 역전 발목이 엉덩이보다 높음 → 다리가 들린 상태 +10%
C5 전방 고꾸라짐 (착석) 앉은 상태에서 머리가 무릎 아래로 떨어짐 +25%
C6 옆으로 기울어짐 (착석) 앉은 상태에서 어깨가 한쪽으로 급격히 기울어짐 +25%
C7 높이 급락 (착석) 앉은 기준선 대비 머리 높이가 급격히 낮아짐 +20%

왜 13개나 필요할까요?

낙상은 한 가지 방식으로만 일어나지 않습니다. 앞으로 넘어지기, 뒤로 넘어지기, 옆으로 미끄러지기, 의자에서 떨어지기 등 다양한 상황이 있어요. V5에서는 규칙이 최종 점수에 직접 기여하지는 않지만, 오탐 필터와 전조 감지 경로에서 여전히 보조 역할을 합니다.

📊 EMA 비대칭 스무딩: 빠르게 반응, 천천히 복귀

AI의 점수를 그대로 사용하면 노이즈(잡음)에 의한 오경보가 많아집니다. EMA(지수이동평균)로 점수를 부드럽게 만들되, 위험할 때는 빨리, 안전할 때는 천천히 반응하도록 설계했습니다.

왜 비대칭일까요?

화재 감지기를 생각해보세요. 연기가 감지되면 즉시 경보를 울려야 합니다 (빠른 반응). 하지만 연기가 조금 줄었다고 바로 경보를 끄면 안 됩니다 (느린 복귀). 실제 화재는 연기가 잠깐 줄었다가 다시 늘어날 수 있기 때문이죠. 낙상도 마찬가지입니다 — 넘어지는 순간을 빠르게 잡되, 혹시 아직 넘어지는 중일 수 있으니 경계를 천천히 풀어야 합니다.

🛡️ 오탐 방지 (11가지 메커니즘)

V5에서는 기존 5가지에서 11가지 FP 방지 메커니즘으로 확장되었습니다. 오경보가 너무 많으면 간호사가 알림을 무시하게 되므로(알림 피로), 오탐 방지가 매우 중요합니다.

👁️

필터 1: 가시성 게이트 (Visibility Gate)

평균 관절 가시성이 0.30 미만이면 프레임 전체를 스킵합니다. 신뢰할 수 없는 데이터를 원천 차단.

"카메라에 일부만 보이는 사람" → 불확실한 판정 방지!
⏳

필터 2: 그레이스 기간 (Grace Period)

감지 시작 후 첫 5프레임은 스킵합니다. 단, 극단적으로 높은 점수는 예외로 즉시 감지합니다.

"카메라 앵글이 막 조정된 직후" → 초기 노이즈 무시!
🔢

필터 3: 연속 프레임 확인

일반적으로 2프레임 연속 낙상 판정 필요. 단, 점수≥0.90 또는 (ML≥0.60 + 점수≥0.70)이면 1프레임으로 즉시 감지.

"한 프레임 반짝 노이즈" → 오경보 방지!
🔍

필터 4: 구부리기 억제 (Bending Suppression)

C1(머리-엉덩이 역전)과 C2(급격 하강)가 있지만 C3(수평)이 없고, 발목이 정지 상태이면 → 물건 줍기 판단.

"바닥에 떨어진 약을 줍는 환자" → 낙상 아님!
🛏️

필터 5: 의도적 눕기 억제 (Controlled Lying)

몸이 수평(C3)이지만 급격한 가속도(N1) 없고 점진적 하강 패턴이면 → 천천히 누운 것으로 판단.

"침대에 천천히 눕는 환자" → 낙상 아님!
🪑

필터 6: 의도적 착석 억제 (Controlled Sitting)

기립→착석 전환 + 점진적 하강 + 가속도 없으면 → 정상 착석 동작으로 판단.

"의자에 앉으려는 환자" → 낙상 아님!
🤸

필터 7: 기립 제어 동작 억제 (Standing Controlled Motion)

서있는 상태에서 급격한 가속도(N1) 없이 상체 움직임만 있는 경우 → 스트레칭이나 운동.

"스트레칭하는 환자" → 낙상 아님!
🛌

필터 8: 장기 누움 면제 (LYING Stable Exemption)

연속 30프레임 이상 LYING 상태이면 낙상 감지를 완전 면제합니다. 이미 안정적으로 누워있는 상태.

"침대에 30초 이상 누워있는 환자" → 낙상이 아닌 안정 상태!
😴

필터 9: 장기 누움 억제 (Long-term LYING Suppression)

연속 10프레임 이상 LYING 상태이면 낙상 점수를 억제합니다. 단기 누움과 실제 낙상을 구분.

"바닥에 의도적으로 누운 환자" → 지속 알림 방지!
🪑

필터 10: 착석 ML 전용 차단 (Seated ML-Only Block)

착석 상태이면서 착석 전용 조건(C5/C6/C7)이 없고 점수 < 0.75이면 → ML만으로는 낙상 감지 차단.

"앉아있는 자세에서 ML이 잠깐 높아진 경우" → 오경보 방지!
🧍

필터 11: 기립 FP 후처리 필터 (Standing FP Post-EMA)

"꼿꼿이 서서 팔만 흔드는 환자" → ML이 잠깐 높아도 무시!

Recall이란?

"실제 낙상을 몇 %나 잡았나?"

100명이 넘어졌을 때, 그 중 95명을 감지했다면 Recall 95.2%. 요양병원에서 가장 중요한 지표입니다 — 낙상을 놓치면 환자가 위험하니까요.

20건 중 19건 감지! 놓치는 비율을 최소화하는 것이 핵심입니다.

Precision이란?

"알림이 울렸을 때, 진짜 낙상인 확률"

100번 알림이 울렸을 때, 95번이 실제 낙상이라면 Precision 94.6%. 오경보가 너무 많으면 간호사가 알림을 무시하게 되므로 중요합니다.

양치기 소년 효과 방지! 경보의 95%가 진짜여야 신뢰할 수 있습니다.

F1-Score란?

"Recall과 Precision의 균형 점수"

둘 다 높아야 높은 점수가 나옵니다. Recall만 높고 Precision이 낮으면 (혹은 그 반대면) F1은 낮아집니다. 두 마리 토끼를 다 잡았는지를 보여주는 종합 지표입니다.

학교 성적으로 비유하면, 국어 90 + 수학 95 → 종합 92.5점

왜 FP와 FN 모두 중요한가?

FP(오탐) = 알림 피로: 가짜 알림이 많으면 진짜 때도 무시하게 됨

FN(미탐) = 안전 위협: 실제 낙상을 놓치면 환자가 위험

의료 현장에서는 FN이 더 치명적이므로 Recall 우선!

FP는 "헛발질", FN은 "놓침". 놓치는 게 더 위험합니다.

*Accuracy와 Recall은 왜 직접 비교할 수 없을까?

Accuracy(정확도)는 전체 데이터 중 맞힌 비율입니다. 예를 들어 영상 100개 중 정상 90개 + 낙상 10개라면, 모든 걸 "정상"이라고만 해도 Accuracy는 90%입니다. 데이터 불균형에 취약하여 낙상을 하나도 못 잡아도 높은 수치가 나올 수 있습니다.

Recall(재현율)은 "실제 낙상 중 몇 %를 감지했는가"만 측정합니다. 낙상 10건 중 9건을 잡았으면 Recall 90% — 정상 데이터가 아무리 많아도 영향을 받지 않습니다. 의료 현장에서는 "낙상을 놓치지 않는 것"이 핵심이므로 Recall이 더 의미 있는 지표입니다.
