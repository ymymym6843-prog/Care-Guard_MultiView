# SENTIO 디자인 레퍼런스 가이드

## 📌 의료/재활 분야 UI/UX 핵심 원칙

### 1. 사용자 특성 고려
- **의료진**: 바쁜 업무 환경, 빠른 정보 파악 필요
- **고령 환자**: 시력 저하, 인지 능력 고려
- **긴급 상황**: 즉각적인 알림 인지 필수

### 2. 디자인 핵심 요소
| 요소 | 권장 사항 |
|------|----------|
| 색상 | 상태별 명확한 구분 (녹색=안전, 노랑=주의, 빨강=위험) |
| 폰트 | 큰 글씨 (최소 14px), 높은 가독성 |
| 레이아웃 | 핵심 정보 중앙 배치, 여백 충분히 |
| 알림 | 시각 + 청각 + 진동 다중 알림 |
| 접근성 | 색맹 대응, 고대비 모드 지원 |

/* 상태 색상 - 높은 대비 */

--danger-bg: #EF444430;

/* 배경 (다크 테마 권장 - 24시간 모니터링 눈 피로 감소) */

--bg-secondary: #1E293B;
--bg-card: #334155;

/* 텍스트 */
--text-primary: #F8FAFC;

--accent: #3B82F6;      /* 파랑 - 정보/액션 */
```

### 2. 레이아웃 구조

```
┌─────────────────────────────────────────────────────────┐
│  헤더: 로고 | 연결상태 | 시간 | 알림 | 설정              │
├────────────┬────────────────────────────────────────────┤
│            │                                            │
│  사이드바   │         메인 비디오 영역                    │

│  - 이벤트   │  상태 카드  │  측정값 카드  │  설정 카드    │
│  - 설정    │  (대형)    │  (실시간)    │  (슬라이더)   │

## 구현 현황

아래는 디자인 레퍼런스에서 제시된 항목의 실제 구현 현황입니다.

### 색상 시스템
| 항목 | 상태 | 구현 위치 |
|------|------|-----------|
| 상태별 색상 (녹/노/빨) | 구현 완료 | `globals.css` (:root, .dark) |
| oklch 색상 포맷 | 구현 완료 | Tailwind v4 + CSS 변수 |
| 다크 테마 기본값 | 구현 완료 | `index.html` class="dark" |

### 레이아웃
| 항목 | 상태 | 구현 위치 |
|------|------|-----------|
| 좌측 사이드바 (접이식) | 구현 완료 | `Sidebar.tsx` |
| 중앙 비디오 + 스켈레톤 | 구현 완료 | `VideoFeed.tsx` |
| 헤더 (로고, 연결상태, 시간, 알림) | 구현 완료 | `Header.tsx` |
| 상태/메트릭/설정 카드 | 구현 완료 | `StatusCard`, `MetricsCard`, `SettingsCard` |
| 이벤트 로그 | 구현 완료 | `EventLog.tsx` |
| 통계 대시보드 (차트, 히트맵) | 구현 완료 | `StatsView.tsx` |
| Safe-Zone 폴리곤 에디터 | 구현 완료 | `SafeZoneEditor.tsx` |
| WebRTC 비디오 플레이어 | 구현 완료 | `WebRTCPlayer.tsx` |
| 회원가입 페이지 | 구현 완료 | `RegisterPage.tsx` |
| 사용자 관리 (admin) | 구현 완료 | `UserManagement.tsx` |

### 타이포그래피
| 항목 | 상태 | 구현 위치 |
|------|------|-----------|
| Pretendard 폰트 | 구현 완료 | `index.html` CDN + `globals.css` |
| Noto Sans KR 폰트 | 구현 완료 | `index.html` Google Fonts |
| 긴급 알림 큰 텍스트 (4xl) | 구현 완료 | `DangerAlertDialog.tsx` |

### 애니메이션
| 항목 | 상태 | 구현 위치 |
|------|------|-----------|
| danger-pulse (깜빡임) | 구현 완료 | `globals.css` |
| border-flash (테두리) | 구현 완료 | `globals.css` |
| alert-shake (흔들림) | 구현 완료 | `globals.css` |

### 접근성
| 항목 | 상태 | 구현 위치 |
