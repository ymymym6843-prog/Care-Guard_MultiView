## 3.2 Zhihan Ye (2024) 논문 상세 비교

### 논문 개요

- **저자**: Zhihan Ye (Harbin Institute of Technology, China)
- **학회**: DAML 2024 - 2nd International Conference on Data Analysis and Machine Learning
- **DOI**: 10.5220/0013486500004619
- **핵심**: YOLOv8 + YOLOv8-Pose 조합으로 92% 정확도 달성

### 3.2.1 기술 스택 비교

| 항목 | SENTIO | Ye (2024) |
|------|-----------|-----------|
| **객체 감지** | YOLO11 | YOLOv8n |
| **자세 추정** | MediaPipe 33점 / YOLO 17점 | YOLOv8-Pose (yolov8x-pose-p6) |
| **분류기** | GRU (시퀀스 기반) | 규칙 기반 (속도/각도) |
| **시퀀스 길이** | 30프레임 | 1프레임 (즉시 판정) |
| **낙상 판정** | ML 확률 + 규칙 앙상블 | 속도/각도 임계값 |

### 3.2.2 성능 비교

| 지표 | SENTIO V4 (GRU) | Ye (YOLOv8+Pose) |
|------|----------------------|------------------|
| **Recall** | **95.2%** | 92%* |
| **Precision** | **94.6%** | 미공개 |
| **F1-Score** | **94.9** | 미공개 |
| **검증 규모** | **424개 영상** | YouTube 1개 |
| **mAP50** | N/A | 0.837 (3클래스) |

*Ye 논문의 92%는 Accuracy이며 Recall과 직접 비교 불가

### 3.2.3 검증 환경 비교 (핵심 차이점)

| 항목 | SENTIO V4 | Ye (2024) |

| **검증 데이터** | **424개 영상 (8각도×4유형)** | "50 Ways to Fall" YouTube 영상 1개 |

| **피험자** | 다양한 연령/성별 | YouTube 영상 (젊은 남성) |

### 3.2.5 낙상 판정 로직 비교

**Ye (2024) - 규칙 기반**:
```
1. 엉덩이/어깨 속도 > 임계값 → 낙상 후보
2. 몸통 각도 < 임계값 → 낙상 후보
3. 낙상 시작~종료 시간 < 1.5초 → 낙상 확정
```

**SENTIO - GRU ML 기반**:
```
1. 30프레임 시퀀스 수집 (33랜드마크 × 3좌표)
2. GRU 모델 추론 → 낙상 확률 (0.0~1.0)
3. 확률 > 0.5 → 낙상 판정
4. 낙상 유형 분류 (전방/후방/측면/전조)
```

## 4. 분석 및 결론

### 4.1 직접 비교의 한계

학술 논문과의 직접 비교는 다음 이유로 제한적입니다:

1. **데이터셋 차이**: 각 연구마다 다른 데이터셋 사용 (UR Fall vs Pre-VFall vs AIHub)
2. **피험자 특성**: 논문들은 젊은 성인 위주, SENTIO는 요양병원 환경 최적화
3. **평가 지표 정의**: Recall/Precision 계산 방식의 미세한 차이 존재
4. **검증 프로토콜**: 교차 검증 방식, 테스트/학습 분리 비율 상이

### 4.2 SENTIO V4 강점

| 강점 | 설명 |
|------|------|
| **CPU 실시간 처리** | GPU 없이 15ms/frame 처리 (요양병원 저사양 PC 대응) |
| **높은 F1** | 94.9로 Recall과 Precision 균형 달성 (알람 피로 최소화) |
| **대규모 검증** | 424개 영상으로 종합 벤치마크 완료 (3방향 낙상 + 정상) |
| **한국 환경 최적화** | AIHub 한국 데이터셋으로 학습 (665,574 시퀀스) |
| **다중 카메라 각도** | 8개 카메라 각도 (C1-C8)에서 검증 완료 |
| **프라이버시 보호** | 스켈레톤 모드 기본 (개인정보보호법 준수) |

### 4.3 향후 과제

| 항목 | V4 현재 | 목표 | 전략 |
|------|---------|------|------|
| Recall | **95.2%** | 97%+ | GRU 재학습 (negative mining) |
| FP | 17건 | 10건 이하 | 강한 패턴 분석 후 필터 추가 |
| FN (SY) | 9건 | 3건 이하 | 측면 낙상 특화 학습 데이터 확보 |
| 검증 영상 수 | **424개** | 500개+ | 다양한 환경/피험자 확보 |

### 4.4 결론

SENTIO V4의 GRU 기반 낙상 감지 시스템은:

1. **Recall 95.2% / Precision 94.6% / F1 94.9**로 학술 논문 수준의 성능 달성
2. **424개 영상** 종합 벤치마크로 통계적 신뢰도 확보
3. **GPU 없이 CPU 실시간 처리** 가능하여 실제 요양병원 배포에 적합
4. **한국 환경 특화** AIHub 데이터셋 (665,574 시퀀스) 학습으로 국내 현장 적합성 확보
5. V1→V4 **4단계 버전 진화**를 통해 F1 89.5 → 94.9 (+5.4) 개선

## 5. 감지 방법 진화 이력

### 5.1 Recall 개선 추이

| 단계 | 방법 | Recall | 개선폭 | 비고 |
|------|------|--------|--------|------|
| 1 | 규칙 4조건 (5% 기준) | 44.4% | 베이스라인 | 규칙 기반만 사용 |
| 2 | 규칙 4조건 (1프레임) | 66.7% | +22.3%p | 판정 기준 완화 |

| 4 | ML 100% 앙상블 | 91.7% | +7.4%p | 24개 영상 기준 |
